Section 1: Conditional probability / הסתברות מותנית
For events A and B on the same probability space, if P(B)>0,
P(A|B)=P(A intersection B)/P(B).
If P(B)=0, this elementary definition is undefined, not zero.

Section 2: Independence / אי תלות
A and B are independent exactly when P(A intersection B)=P(A)P(B).
For P(B)>0 this is equivalent to P(A|B)=P(A).
Disjoint events have empty intersection. If both have positive probability,
disjoint events are dependent: 0=P(A intersection B) != P(A)P(B)>0.
Counterexample: one fair die; A={1}, B={2}; disjoint but not independent.
Zero-probability events satisfy the product definition of independence with every event,
although conditioning on them is undefined in this elementary setting.
