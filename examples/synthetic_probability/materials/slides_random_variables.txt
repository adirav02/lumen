# Slide Deck: Discrete Random Variables & Poisson Distribution

## Slide 1: Random Variables Overview
A discrete random variable maps outcomes in sample space to real numbers.

### Definition: Discrete Random Variable
Content: A function X: \Omega -> \mathbb{R} that takes on at most countably many values.
Assumptions: Domain is sample space \Omega; Range is countable subset of \mathbb{R}
Symbols: X = random variable; \Omega = sample space
Exceptions: Continuous variables require density functions
Dependencies: probability-space

### Formula: Poisson Distribution PMF
Content: P(X = k) = (e^{-\lambda} * \lambda^k) / k! for k \in {0, 1, 2, ...}.
Assumptions: \lambda > 0; k is a non-negative integer
Symbols: \lambda = average arrival rate; k = number of events; e = Euler's number
Exceptions: Undefined for negative k or \lambda \le 0
Dependencies: discrete-random-variable

### Theorem: Expectation and Variance of Poisson
Content: For a Poisson random variable X ~ Poisson(\lambda), both E[X] = \lambda and Var(X) = \lambda.
Assumptions: X is Poisson distributed with parameter \lambda > 0
Symbols: E[X] = expected value; Var(X) = variance; \lambda = Poisson parameter
Exceptions: None
Dependencies: poisson-distribution
