# Examples

[Harbor Systems course](<Harbor systems - semester 1/00 syllabus (downloaded).txt>)
is a fictional full-semester course dropped here as loose student-style files.
Lecture notes, homework, quizzes, exams, instructor answers, CSVs and unfinished
scratch notes are mixed between the root, downloads and exams folders. All
content is generated fiction. Instructor keys are separate from question papers.
The course is local and gitignored. Nothing has been imported, learned, indexed,
registered or assessed. There is no course manifest or generated knowledge bank.

The old audit, synthetic-probability and beta course folders have been removed.
Existing [educational evaluation fixtures](educational_evaluation/README.md)
remain separate; they are historical evaluation data, not the new course.
