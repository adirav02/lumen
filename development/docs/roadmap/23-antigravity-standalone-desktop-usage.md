## 23. Antigravity standalone desktop usage

Explicit `configure-usage` host `antigravity-app` installs project-local
`PostInvocation`/`Stop` hooks, independent of the CLI status line. The callback
requires the exact mounted workspace and desktop transcript identity and records
only raw numeric counters from unique planner response steps. Latest fragments
replace previous values; repeated snapshots replay. Ambiguous cache-inclusive
input remains unknown. Existing hooks are preserved with atomic settings writes,
locking, backups and idempotent setup. Conflicting named hooks require review.

Acceptance includes scoped exclusion before transcript reads, malformed counters,
partial final lines, privacy, duplicate steps, replay, settings preservation and
subprocess output contract. The parser also read two real saved desktop app
transcripts into temporary ledgers with synthetic workspace assertions; this is
offline format validation, not native hook evidence. The first restarted desktop 2.24.0 practice session produced no hook snapshot.
A fallback collector now reads workspace URIs and conversation identity from the
native summary database before opening matching transcripts. Actual practice-run
counters were captured without scanning unrelated transcript bodies. A local
user systemd watcher is enabled for this checkout. Hook delivery remains an open
native gate. No in-app usage widget is implemented.
